# HỮU'S GAME CENTER

Dự án Website Game Arcade trực tuyến phong cách Neon Cyberpunk hiện đại, được tối ưu hoàn chỉnh cho cả máy tính để bàn (PC) và thiết bị di động (Mobile).

## 🚀 CÁC TÍNH NĂNG VÀ TRÒ CHƠI

1. **Rắn Săn Mồi (Snake Neon):**
   - 10 Bản đồ với màu sắc tường neon đổi màu đặc sắc.
   - Cơ chế bộ đệm phím chống tự quay đầu chết oan.
   - D-pad ảo cho điện thoại cảm ứng & 4 phím mũi tên trên PC.
   - Mục tiêu 100 điểm để chiến thắng.

2. **Chém Hoa Quả (Fruit Slide):**
   - Cơ chế vuốt kiếm (Blade) mượt mà trên màn hình cảm ứng & chuột máy tính.
   - Không có màn hình Map Select dư thừa.
   - Hệ thống 3 mạng, hoa quả bay tự nhiên, bom xuất hiện an toàn khi đạt từ 25 điểm.
   - Mục tiêu 100 điểm để giành chiến thắng.

3. **Phá Gạch Siêu Cấp (Brick Breaker):**
   - 10 Bản đồ chia làm 5 cấp độ khó với thiết kế tường ngang và xoắn ốc luồn lách.
   - Kích thước gạch nhỏ gọn, số lượng gạch phong phú.
   - Vật phẩm Power-ups đặc sắc:
     - **💥 Explosion:** Kích hoạt vụ nổ tại bóng, phá sạch gạch trong bán kính 3 ô.
     - **⚡ Double:** Nhân đôi số bóng trong 10 giây.
     - **🔥 Triple:** Nhân ba số bóng trong 10 giây.
     - **👑 Combo:** Kích hoạt đồng thời cả 2 sẽ nhân gấp 6 lần số bóng!
   - Giới hạn 7 phút mỗi bản đồ, 3 mạng.

4. **Hệ thống Âm thanh Web Audio API thuần:**
   - Tạo âm thanh điện tử tổng hợp trực tiếp (không phụ thuộc file ngoài).

---

## 💻 HƯỚNG DẪN CHẠY TRÊN MÁY TÍNH

1. Giải nén file zip `huu-game-center.zip`.
2. Mở file `index.html` trực tiếp bằng bất kỳ trình duyệt nào (Chrome, Edge, Safari, Firefox).
3. Không cần cài đặt `Node.js` hay chạy `localhost`.

---

## 🌐 HƯỚNG DẪN TRIỂN KHAI MIỄN PHÍ TRÊN GITHUB PAGES

1. Đăng nhập vào tài khoản [GitHub](https://github.com) của bạn.
2. Tạo một Repository mới (ví dụ: `huu-game-center`), chọn chế độ **Public**.
3. Tải toàn bộ các file trong thư mục đã giải nén (`index.html`, thư mục `css`, `js`, `README.md`) lên nhánh `main`.
4. Vào mục **Settings** của repository -> Chọn menu **Pages** ở thanh bên trái.
5. Tại mục **Branch**, chọn `main` và thư mục `/ (root)`, sau đó nhấn **Save**.
6. Sau 1 - 2 phút, GitHub Pages sẽ cung cấp cho bạn một đường link công khai dạng `https://<ten-tai-khoan>.github.io/huu-game-center/` để mọi người cùng chơi!
